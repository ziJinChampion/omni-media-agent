# omni-media-agent

> 自动化内容运营矩阵平台 —— 用 AI Agent 全自动运营多个垂类自媒体账号

一个面向「内容矩阵」场景的自动化运营平台：Agent 每天自动搜索垂直领域的信息与图片素材，生成符合平台风格的推文，并自动发布到小红书、抖音等渠道。平台同时提供多账号矩阵的统一管理能力。

## 典型场景

| 账号类型 | Agent 每日工作流示例 |
| --- | --- |
| 动物科普号 | 搜索"世界上奇特的动物"选题 → 检索资料与高清图片 → 生成科普推文 → 发布 |
| 地理科普号 | 搜索地理冷知识/地貌奇观 → 配图 → 生成推文 → 发布 |
| 更多垂类 | 历史、天文、美食、冷知识……可通过配置无限扩展 |

## 核心能力

### 1. 内容生产 Agent（Content Agent）
- **选题发现**：每日定时搜索领域热点与长尾选题，去重历史内容，避免重复发布
- **素材检索**：文本资料 + 图片素材双通道采集，来源可追溯
- **内容生成**：按平台风格模板（小红书种草体 / 抖音文案体）生成推文，含标题、正文、标签、配图说明
- **质量闸门**：LLM-as-Judge 对成稿打分（准确性、吸引力、平台合规），不合格自动重写

### 2. 账号矩阵管理（Account Hub）
- 多平台、多账号统一接入（小红书 / 抖音 / ……）
- 账号凭证与 Cookie 的加密存储与轮换
- 发布频率、时段、内容配比可按账号独立配置
- 发布结果回执与失败重试

### 3. 调度与编排（Scheduler & Orchestration）
- 基于 cron 的每日定时任务，按账号独立排程
- 选题 → 检索 → 生成 → 审核 → 发布 全链路状态机，可观测、可回放
- 人工介入点：支持"自动发布"与"人工审核后发布"两种模式

### 4. 数据看板（Analytics）
- 发布量、成功率、互动数据（点赞/收藏/评论）按账号聚合
- 选题效果回流，反哺选题策略

## 架构总览

```
┌─────────────────────────────────────────────────────────┐
│                     Dashboard / 管理台                    │
├─────────────────────────────────────────────────────────┤
│  Account Hub 账号矩阵管理  │  Analytics 数据看板          │
├─────────────────────────────────────────────────────────┤
│              Scheduler 调度器（cron / 状态机）            │
├─────────────────────────────────────────────────────────┤
│   Content Agent 内容生产流水线                            │
│   选题 → 检索(文本+图片) → 生成 → Judge审核 → 待发        │
├─────────────────────────────────────────────────────────┤
│   Publisher 发布适配层                                    │
│   小红书 adapter │ 抖音 adapter │ 更多平台 adapter        │
├─────────────────────────────────────────────────────────┤
│   存储层：PostgreSQL（账号/任务/内容） + 对象存储（素材）  │
└─────────────────────────────────────────────────────────┘
```

详细设计见 [docs/architecture.md](docs/architecture.md)。

## 合规说明

本项目仅用于学习与技术研究。自动化发布需遵守各平台的服务条款与社区规范，建议控制发布频率、保证内容原创性与信息准确性，避免触发平台风控。
